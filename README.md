# f1game

A basic browser-based Formula 1 inspired lane-dodging game.

## How to play

1. Open `index.html` in a browser.
2. Use the **left** and **right** arrow keys to switch lanes.
3. Avoid incoming rival cars.
4. Your score and speed increase the longer you survive.
5. Click **Restart Race** after a crash to play again.

## Files

- `index.html` - game layout and HUD
- `style.css` - game styling
- `game.js` - gameplay loop, controls, spawning, and collision logic
